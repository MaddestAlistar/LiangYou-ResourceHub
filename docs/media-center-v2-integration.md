# 影视情报中心整合版

基于 70b8925 的最新网页与独立 Worker 整合，保留原有站点和服务部署。

- 作品档案采用精确跨站 ID 合并，评分保留原始尺度、人数、来源和时间；不对各站分数求混合平均。
- 详情分为概览、季集与播出、观看与字幕；地区渠道沿用 JustWatch via TMDB Worker。该 Worker 的 CORS 仅允许正式 GitHub Pages 域名，本地预览无法调用。
- 一套本地片单：想看、在看、看完；支持 JSON 导入导出与电影 Letterboxd CSV。旧工具箱记录自动按确切 ID 迁移，保留旧存储副本，较新状态优先。无账户同步。
- 猫眼累计票房前十采用独立榜单展示，不按片名强行关联 TMDB。万元转亿元，保留抓取时间和原站链接。
- Kitsu、B站、Filmarks、Simkl、猫眼提供原站 ID 独立评分查询；查询结果不自动写入作品档案。无可靠 ID 对照时不合并。Filmarks 与猫眼为非官方公开网页实验接口；B站和 Filmarks 可能使用注明时间的验证快照。
- MyDramaList 教育用途服务、未验证映射的其他接口暂未并入作品评分。新增 API 可用不等于所有作品均已覆盖。

验证：19 项采集/作品档案测试、9 项片单测试、网页结构校验及 JavaScript 语法检查。移动预览实际读取 Kitsu 评分与猫眼票房榜，343px 内容宽度无横向溢出。发布后另验正式域名地区渠道。
