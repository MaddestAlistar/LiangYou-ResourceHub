✓
网站资源收费吗？+

本网站只提供公开资源导航和链接，不收取访问费用。各 App 自身是否需要购买、订阅或注册，由其开发者决定。

复制链接后无法导入怎么办？+

请先确认目标 App 支持对应 JSON 或规则格式，而不仅仅是支持任意 URL。不同播放器可能需要专用版本，可前往项目 GitHub README 查看兼容说明。

资源以后更新，需要重新复制吗？+

一般情况下，原订阅地址不变，支持远程刷新的 App 可获取原仓库更新；实际刷新机制由各 App 决定。徽章库部分独立新版本会有新的导入地址，请关注项目说明。
